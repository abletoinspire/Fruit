# Система подготовки данных, обучения и инференса моделей для анализа фруктов на конвейере

Проект содержит набор скриптов для подготовки изображений, генерации синтетических датасетов, обучения моделей сегментации и классификации фруктов, а также инференса на изображениях и видеопотоке.

Основная задача проекта - автоматическое обнаружение фруктов на изображениях конвейерной ленты, выделение области фрукта и определение его состояния.

## Основные задачи проекта

Проект решает несколько связанных задач:

1. автоматическая разметка изображений;
2. генерация синтетических обучающих данных;
3. обучение универсальных моделей сегментации;
4. проверка нескольких гипотез по архитектуре модели;
5. инференс обученных моделей на изображениях и видео.

## Структура файлов

| Файл | Назначение |
|---|---|
| `yolo_train.ipynb` | Автоматическая разметка изображений. Используется для первичной подготовки разметки и ускорения процесса создания датасета. |
| `mosaic.py` | Генерация синтетического датасета в форме мозаики. Скрипт объединяет несколько изображений в одно изображение и переносит аннотации в новый COCO-файл. |
| `generator.py` | Генерация синтетического датасета со случайным фоном. Используется для увеличения разнообразия данных за счёт вставки фруктов на разные фоны. |
| `new_train.py` | Первая универсальная модель. Обучает модель для сегментации типов фруктов на основе COCO-разметки. |
| `instance.py` | Инференс первой универсальной модели. Используется для обработки видео или изображений обученной универсальной моделью. |
| `dataset_generator.py` | Генерация синтетического датасета с фоном конвейерной ленты. Скрипт размещает фрукты на заранее заданной области ленты и формирует новый COCO-датасет. |
| `train_0.py` | Первая модель для конвейерного производства. Базовый вариант модели, адаптированный под задачу обработки изображений с конвейерной ленты. |
| `train_A.py` | Модель для проверки гипотезы A. Обучает вариант, ориентированный на определение свежести/испорченности фрукта без отдельной классификации типа фрукта. |
| `train_B.py` | Модель для проверки гипотезы B. Использует объединённые классы вида `fresh_apple`, `rotten_banana`, `fresh_orange` и т.д. |
| `train_C.py` | Модель для проверки гипотезы C. Использует условную классификацию качества с учётом типа фрукта. |
| `inference_A.py` | Инференс модели гипотезы A на изображениях. |
| `inference_B.py` | Инференс модели гипотезы B на изображениях. |
| `inference_C.py` | Инференс модели гипотезы C на изображениях. |
| `inference_video_A.py` | Инференс видеопотока для модели гипотезы A. Используется для обработки видео с сохранением результата в новый файл. |
